# Horizon Cap Worlds

Sections 1 and 2 of the Horizon Cap Worlds corporate website: hero and About. React, Vite, Tailwind CSS, Remix Icons and Framer Motion. Inter and Outfit are bundled locally.

## Run

```sh
npm install
npm run dev -- --host 127.0.0.1
```

## Production

```sh
npm run build
npm run preview
```

The About navigation and hero discovery action scroll to the About section. Other navigation and hero actions open accessible information dialogs. Investment sectors can be switched within the investment dialog. No backend, sign-up flow, invented returns, or investment transactions are included. Leadership profiles and specific investment plans require supplied company content.

The original supplied `public/assets/Horizon Cap Worlds Gold Logo.png` is used in both the navbar and footer. The hero is a generated illustrative composition, not a photograph of company-owned assets. See `public/assets/IMAGE-PROMPT.md` for provenance.
